# TG Hub Shell

Окно с вкладками: слева сети (ТГ Хаб, ВК, …), сверху аккаунты, в центре настоящий сайт.
У каждой вкладки свой профиль — свой вход и куки.

## Скачать готовую программу
https://github.com/kostyanmolokov-cmyk/tg-hub-shell/releases/latest/download/TG-Hub-Shell.exe

## Запуск из исходников (Windows)
1. Установите Node.js (nodejs.org, версия LTS).
2. Дважды щёлкните `start.bat` (первый запуск скачает Electron).
3. Для одного portable-файла: `npm run dist`, готовый .exe появится в папке `dist`.

## Управление
- `+` слева — добавить сайт/сеть (например, Одноклассники: `ok.ru/messages`).
- `+` сверху — ещё один аккаунт этой сети (отдельный вход).
- Двойной щелчок по вкладке — переименовать, `✕` — закрыть и забыть вход.
- Правый щелчок по сети слева — изменить название/адрес или удалить.
- Красный кружок — число непрочитанных из заголовка страницы `(3) …` (если сайт его показывает).

Настройки хранятся в `%APPDATA%\tg-hub-shell\shell.json`.

## ВК и другие сайты внутри хаба
Во вкладке «ТГ» (хаб) в левой панели есть кнопка 🌐 — она открывает ВКонтакте и другие сайты прямо в рабочей области хаба
(приложение рисует сайт поверх этой области; вход запоминается отдельно). Список сайтов хранится в вашем зашифрованном хранилище. Вкладки слева в оболочке остаются как запасной вариант.
