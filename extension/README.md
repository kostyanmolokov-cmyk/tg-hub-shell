# ТГ Хаб — расширение для браузера

Нужно только для компьютера (Chrome, Edge, Opera, Яндекс Браузер).

## Установка
1. Скачайте `TG-Hub-Extension.zip` и распакуйте в любую папку (папку потом не удаляйте).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку, где лежит `manifest.json`.
5. Обновите страницу ТГ Хаба — в «🌐 Сайты» сайты откроются внутри хаба.

## Обновление
Скачайте новый архив, распакуйте поверх старой папки и нажмите ⟳ на странице расширений.

## Что делает и чего не делает
- Работает только когда сайт открыт из ТГ Хаба и только для сайтов из вашего списка.
- Снимает запрет сайта на показ в рамке и делает cookie этих сайтов пригодными для рамки (SameSite=None).
- Подставляет логин и пароль в поля входа; кнопку «Войти» не нажимает.
- Ничего не отправляет на сторонние серверы.
